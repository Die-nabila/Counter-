STEP COUNTDOWN

SAUVEGARDE

Guide
Exporter
1. Appuie sur « Générer mon code de sauvegarde ».
2. Appuie sur « Copier le code ».
3. Colle-le dans un endroit sûr : Notes, Google Keep, ou un message à toi-même (WhatsApp, e-mail).

Importer (nouveau téléphone ou après un effacement)
1. Ouvre Step Countdown, puis « Sauvegarde ». Sur un appareil neuf, crée d'abord un challenge (n'importe quelles valeurs).
2. Copie ton code depuis tes Notes / ton message.
3. Colle-le dans la zone « Importer », puis appuie sur « Importer » et confirme.
Les données actuelles sont remplacées par celles du code.
